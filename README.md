# The Rupture Files

### An Ethnographic Guide for Another World

## What this is

The Rupture Files is a modular, ethnographic guide to living through rupture,
built for a world where the infrastructures we rely on can fail, degrade, or
disappear. It draws on ethnographic methods to document not only *what to do*
but also *how rupture is lived, understood, and enacted* by those inside it.

The project is designed to outlast its hosting. If the infrastructure that
keeps this site online is part of what ruptures, the guide needs to
already exist elsewhere, on a hard drive, in a zine, or on paper. The artifact's
survivability is a design constraint, not an afterthought.

## Core distinction: Event Ruptures vs. Regime Ruptures

Not all ruptures behave the same way. This project treats two categories as
ontologically distinct: different processes, different temporalities,
and different ways of being lived, and gives each its own structural grammar
rather than forcing both into a single template.

### Event Ruptures
Discrete, bounded ruptures with an onset, a duration, and a resolution.
Earthquake, flood, fire, grid-down, and civil disruption.

- **Process:** trigger → cascade → stabilization
- **Enactment:** mobilization — you act on a timeline
- **Grammar:** Before / During / After
- **Form:** the closed case file — consulted in a hurry, once

### Regime Ruptures
Continuous, ambient ruptures without a clean edge, a baseline that shifts
under sustained pressure. Extreme heat, toxicity, and chronic ecological
degradation.

- **Process:** accumulation, exposure, dose over time
- **Enactment:** literacy, monitoring, adaptation — built into how you live,
  not grabbed in a moment
- **Grammar:** Baseline / Threshold / Adaptation
- **Form:** the open file — revisited and updated, closer to chronic
  management than incident response

A single phenomenon can appear in both tracks: a heatwave is an acute,
Event-shaped episode nested within the larger, ongoing Regime condition of
warming. When that happens, the Event entry cross-references the Regime
entry, and vice versa.

## File numbering

Every entry in the guide is a **file** — numbered, indexed, and designed to
serve as a standalone artifact (a zine, a printable card, or a site page)
independent of the whole system.

| Series | Track  | Category                                          |
| ------ | ------ | ------------------------------------------------- |
| 000    | —      | Orientation & Methodology                         |
| 100    | Event  | Core Principles (universal)                       |
| 200    | Event  | Core Systems (universal)                          |
| 300    | Event  | Scenarios (rupture-specific)                      |
| 150    | Regime | Standing Conditions / Ambient Baselines           |
| 250    | Regime | Regime Systems (monitoring, literacy, governance) |
| 350    | Regime | Regime-specific entries (heat, toxicity, etc.)    |
| 900    | —      | Reference (checklists, legends, glossary)         |

Sub-indexing indicates internal breakdowns within a file:
- Event files: `RF-201.1` (Before) / `.2` (During) / `.3` (After)
- Regime files: `RF-251.1` (Baseline) / `.2` (Threshold) / `.3` (Adaptation)

## The litmus test

If a sentence in a scenario- or regime-specific file (300s/350s) could be
pasted unchanged into a *different* scenario or regime file, it belongs in
the universal layer (100s/200s or 150s/250s) instead. Scenario-specific files
only indicate how a given rupture corrupts, modifies, or intensifies a universal
system — they do not repeat it.

## Formats

The same file content is designed to move across formats without rewriting:

- **Interactive site** — browsable by track, series, or timeline
- **Standalone PDFs** — one file, print-ready, for offline/paper use
- **Fanzines** — selected files bound into a themed collection
- **Full offline archive** — the entire repository, downloadable as a `.zip`,
  runs locally with no server or connectivity required

## Status conventions

Each file carries a status tag because this project is built sequentially by
priority rather than all at once:

- `active` — researched, drafted, cross-referenced
- `draft` — in progress, structure set, content incomplete
- `pending` — named and numbered, not yet researched

## Theoretical framing

This project sits adjacent to work on the collapse of global industrial
civilization, informed ethnographically rather than predictively. In particular,
Regime Rupture entries draw on the concept of slow violence: harm
that is gradual, cumulative, and unspectacular, and on this project's
parallel work on toxic afterlives and thermal governance.

Structural and tonal inspiration: *The Asthma Files* / PECE, *A Pattern
Language* (Christopher Alexander), the Whole Earth Catalog archive, the Dark
Mountain Project.
